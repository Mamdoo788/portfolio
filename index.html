The fourth state is the one that matters. A regime control that lets you choose the regime is a settings menu pretending to be a measurement — I removed exactly that from the screener and replaced it with a read-only banner. You can override the weights. You cannot fake the state.

The single most consequential correction in the platform, and the one most backtests never make.

Test against today's membership across all history and every one of those exits silently disappears. The result improves for a reason that has nothing to do with the strategy.

Every build round closes through a script that snapshots state, commits with the round label, pushes, and reports the hash. The runner pulls on a schedule and restarts. Git is not a backup here — it is the synchronisation mechanism between the machine that builds and the machine that runs.
Protocol is bidirectional: the session fetches and confirms it is a fast-forward before mirroring, so work committed from either side is never overwritten.

Context loss between sessions is the failure mode that quietly defeats most AI-assisted engineering. Decisions get re-litigated, corrected numbers resurface, the same bug is written twice. This is the fix — and it is infrastructure, not a habit. It is also what makes the correction loop in section 04 hold: a guardrail is only permanent if something remembers it.
